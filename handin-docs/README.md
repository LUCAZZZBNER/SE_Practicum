# 课程项目提交材料

本目录用于整理《软件工程综合实践》课程项目的设计文档、开发过程材料和最终验收材料。

设计阶段先完成项目说明、架构设计、数据库设计、TDD 测试计划、需求迭代基线和交叉验收检查表。测试日志、覆盖率报告、实际迭代结果、开发日志与验收结论在开发和验收过程中持续补充。

## 目录说明

1. `01-项目说明`：项目背景、目标、功能范围、运行方式和项目成果说明。
2. `02-架构设计`：系统分层、模块划分、接口约定和架构迭代说明。
3. `03-数据库设计`：数据模型、表结构、字段、约束和关系说明。
4. `04-TDD测试报告`：设计阶段的测试计划，以及开发阶段的测试结果、覆盖率、测试日志和回归记录。
5. `05-需求迭代记录`：设计阶段的需求基线，以及各阶段需求变化、影响分析、实现方案和验证结果。
6. `06-团队分工与开发日志`：成员职责、任务安排和开发过程记录。
7. `07-交叉验收`：设计阶段的验收检查表，以及验收阶段的检查记录、问题清单和验收结论。
8. `08-AI辅助使用记录`：项目中使用 AI 辅助工具的情况记录。

各部分的正文和证据材料应放入对应目录，图片、日志和导出报告不要散放在本目录根路径下。设计文档中的接口、数据结构、状态和业务规则发生变化时，应同步修订相关文档并记录变更原因。
